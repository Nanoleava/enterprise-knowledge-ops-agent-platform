# 项目依据文档

本目录保存项目实施所依据的路线图与阶段指导，使仓库在其他工作地点克隆后仍具备完整上下文。

- `java-backend-agent-project-roadmap.md`：Java 后端 + Agent 学习路线、阶段边界、验收标准和后续计划。
- `stage4-day1-project-modification-guideline.md`：阶段 4 DAY1 文档上传与解析的具体工程规则。

文档中的 Windows 绝对路径是原工作站的历史检查信息，不是新环境必须复刻的目录。迁移后应以当前仓库内容、`README.md`、阶段实施报告和实际测试结果为准。

这些文档不包含运行所需密钥。数据库密码、JWT 密钥、Token、本地数据库数据和用户上传文件都不能提交到 Git。
